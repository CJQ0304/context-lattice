## 0. 本版（1.2.0）改了什么

**给「压不动的整块素材」一个原子形态：事件节点（`E` 行）。** 这是**新增能力**（按本包 `CHANGELOG.md` 自己的语义化规则：minor = 新增能力 → 1.1.1 升至 **1.2.0**，而不是 patch 号）。

- **新行类型 `E` + 三个新子命令**（`event` / `fetch` / `plan`）+ `read --fetch`：库里只留「摘要 + 来源指针 + 字节数 + 内容哈希」，**原文不进库也不进窗口**，需要时按需取回并校验。
- **门控把 `k` 这个参数消掉了**：块级断点从 `k > (1+r)/(1−r)` 降到 `k > 1/(1−r)`，规则退化为「**读过的块就压存**」——既不用预估也不用观测。
- **本轮修掉 3 处真缺陷**（第 5.6 节）：内嵌副本**掩盖源被改写**、叶子种类**隐式缺省为 R**（将来新增行类型会静默降级）、交付包内**悬空引用**。
- **文档欠债一次性补齐**：独立执行者在真实任务里指出「`E` 行属于**代码领先文档一整个特性**」—— `store-format.md` 对事件节点**零提及**。本轮把 `store-format.md` / `SKILL.md` / `README.md` / 三份 `templates` / `split-rules.md` / `lifecycle.md` / `degradation.md` / `compression-strategy.md` / `coverage-matrix.md` 全部同步（不变量 15 → 20、降级 16 → 19）。
- **真实场景测试**（本轮新增，第 7.3 节）：层 A 机械测量真实语料；层 B **两个独立实例**跑同一道真实开发需求，判据在看到产物前冻结。
- **1.1.0 / 1.1.1 的内容本轮未改**：作用域、生命周期、跨库索引的行为一字未动（套件 10 / 11 断言数不变即为证）。

### 0.1 回溯：1.1.0 新增了什么

起因是一个观察：本技能已经把长会话压得很紧凑，但**同一句内容该活多久、该在多大范围里生效**从没被回答过；而宿主记忆系统（用户级备注 / 工作区备注 / 每日日志）恰好有一套作用域与生命周期策略，却缺少结构——**长了就必须整篇读**。两者是同一个问题的两个高度，于是把缺口互相补上。

| 新增 | 内容 |
|---|---|
| **三层作用域** `user` / `proj` / `task` | 头部可选 `| scope:` 自描述段（`init --scope` / `add --scope` / `--scope -` 清除）；限定名如 `proj:demo`。旧文件无该段一律视为「未声明」，**不做任何推断** |
| **生命周期标记** `钉住` / `长期` / `暂态` | 复用行尾 ` [xxx]` 语法（**格式未变**）；`prune --aging --days N --today D [--emit-promote F]` 按「标记 × 年龄」决定动作。`--today` 必须显式给 |
| **跨库索引与定位** `index` / `find` | 把渐进披露从「单库内部」提升到「全库之间」。索引只含键层，体积与内容量无关；坏库只跳过不中断；索引缺失时逐库扫描仍可用 |
| **`references/lifecycle.md`** | 作用域判定程序（第 0 步）、三档问句、老化口径、升格判据、跨库导航纪律、失效信号 |
| **`references/host-memory-adapter.md`** | 三层作用域 ↔ 实际记忆文件的映射、两条接线路线，并补上宿主流程缺的那一环——**「30 天蒸馏凭什么判断哪条值得留」现在有判据了** |

**边界守住的一条**：`read` 保持**严格只读**（无副作用）。因此「升格」只用**写入侧可见的显式信号**判定，不靠 `read` 的引用计数——代价是升格偏保守、可能漏升，这是**有意识地选择保守**：漏升只是少升一条，误升会污染长期记忆。

## 7. 关 3 · 行为层验证（1.1.1 轮新增，回答当时标注为「未测」的问题）

### 7.1 作用域判定行为层探针（此前明确标注「未测」）

**为何要重做**：套件 10 的 56 条断言是**脚本层**——它只能证明「脚本按规则处理给它的 scope 值」，证明不了「模型在真实输入上把域判对了」。这两件事必须分开测，不能拿前者当后者的证据。

## 10. 已知限制（坦诚标注，非未处理缺陷）

1. **收敛关卡未用官方工具验收**：官方 `convergence-matrix-tool` 经五条通道确认不在本机；以同 CLI / 同硬卡项 / 同规格文件的等效实现替代，见第 4 节。
2. **H3 的真实增益是 0%，不是 400%**：1.1.0 上的**独立实例** A/B 显示信息保真打平（A 100 / B 100 / B 100 → **0%**）。技能的真实优势在**成本（↓42.3% / ↓56.8%）与可校验、可复现**，不在「记得更多」。旧版 400% 的构成已逐项拆解（第 8.1 节）——**以后再引用 400%，必须同时引用本条**。
3. **作用域判定的行为层已测，但只测了「常识主导」的一层**：**补规则后 100%（13/13）、0 抖动**；而无规则的 N 组也能到 **96.2%**，说明这一层**偏容易**。**更难的一层仍未测**：多项目嵌套下的作用域继承、长上下文里的作用域回溯、两处作用域声明冲突的消解。
4. **作用域判错无法被内核发现**：内核只能保证 `scope:` 是合法枚举（`V15`），**不能保证值判得对**。缓解手段是「宁可窄不可宽」默认策略 + 目录↔声明 `mismatch` 提示。这是**有意的边界**——判对依赖人的判断，不能靠校验器兜住。
5. **索引会漂移**：索引是某一时刻的快照，之后任何库修改都不自动更新。**索引缺失或过期时逐库扫描仍完全可用**——索引只是加速与导航，不是主干硬依赖。
6. **升格只搬运、不删除、不自动**：`--aging --emit-promote` 只生成候选文件，不写入目标库、不删源库副本。升格前必须由人确认；`长期` 标记只是「值得考虑」而不是「已经升格」。
7. **域分区的目录约定是运行假设**：`user/ proj/ task/` 是**建议**路径，不是内核要求；换宿主环境需重画映射表（见 `host-memory-adapter.md`），内核本身不变。
8. **短对话会反膨胀**：实测 12 轮 234 字符 → 存储 529 字符（↑126%）。本技能价值主要在**反复回顾的累计节省**，不在单次体积。`stats` 会原样打印负压缩率，不截断。
9. **`--budget` 是软上限**：key 层永不裁，故 key 层自身超预算时输出会略超预算。
10. **无并发合并**：并发写同一文件不丢文件、不产生半成品，但**会丢更新**（读-改-写竞态，无文件锁）。预期用法是单智能体串行写入。
11. **生命周期标记会让存储变长**：每个标记约 5–6 字符，无差别铺满会明显变长。口径是「只在有实际寿命判断时才打」，无标记是合法默认状态。
12. **平台校验项是本地判据库的超集**：闸门 PASS ≠ 平台必过。若日后拿到驳回原文，需当天补判据与负向夹具。
13. **行为层 rubric 是「见到真实产物之后」调过的，不是预注册的**：3 处误判（2 处误报 + 1 处漏判）在实测中被发现并修正，三处修正**全部朝不利于技能结论的方向**（B 组分数上升、增益下降），因此不构成偏袒；但这仍**降低了这份报告的独立性**——「0% 增益」应被理解为**在修好的判据下**的结论。
14. **行为层采样量 n=2，统计效力弱**：B 组产物长度极差 **33.5%**、N 组准确率 **7.7pp 抖动**，都只能当**指示值**，不能当分布参数；「R 组 0 抖动」同样可能是采样不足的表现。
15. **同源偏差没有被消除**：行为层执行者与作者是**同一模型**，14 条探针的 ground truth 由作者按规则行推出、**无外部标定**。本轮消掉的是「作者手写产物」与「作者目测判分」两处，**没有**消掉同源本身；**跨模型稳定性仍未验证**。
16. **行为层测试无法进自动回归**：它们需要真实模型采样，因此不进 `test_all.py` 的自动化轮次。进自动轮次的是**评分器本身**（套件 12 的正负夹具），保证「裁判」不会悄悄失效；但「被测对象的行为」仍需人工发起新一轮采样。
17. **真实场景测试（1.2.0）的效力边界**：层 B 是 **`n=2`、执行者与作者同源、单题单轮**；那 19.4% 的成本差**不能算作技能的功劳**（是行为差异，两臂都直接用通用文件读取把活干完了）。层 A 的工作集给了**保守 / 乐观两个口径**，真实值落在区间内而不是一个点。
18. **导航层的厚度是取舍、不是定值**：同一份语料，粗粒度索引（按文件与约定）实测 **925 token**，细粒度导航层（按每个结构单元）实测 **5,757 token**，差 **6.2 倍**。报索引体积时必须带上口径，否则这个数没有意义。
    另一个更细的口径坑：索引里带事件节点的**内容哈希**，而十六进制串的 token 切分**不是按长度成比例的** —— 正文改动一个字节、哈希变一次，索引 token 就会抖 ±几个。所以这个绝对值同样「绑定包版本」。
19. **悬空引用检查器只认 ASCII 文件名**：含中文的路径不检查（那类字符串更可能是散文而非引用）。这个局限是**实测**出来的 —— 第一次负向注入用中文名做探针，检查器完全不响。
