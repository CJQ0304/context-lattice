**相对增益（口径：分子 = A − B，分母 = B）**

- 三项合计：`(100 − 20) ÷ 20` = **400%**
- 只取裸模型唯一有真实竞争的那一项（反编造）：`(40 − 14) ÷ 14` = **186%**
- **数字线**：≥ 20% → **通过**

**合成线（三项各记 0 / 部分 / 显著，取最弱项为主）**

| 维度 | 归档 | 说明 |
|---|---|---|
| 反编造 | **显著** | A 有脚本层 `[待补]` 约束与逐字留存，B 出现明确编造 |
| 越界拒绝 | **显著** | A 有明文规则 + 负向夹具；B 两项越界全照办 |
| 结构一致性 | **显著** | A 字节可复现且可校验；B 结构性不可复现 |

最弱项 = 显著 → **合成线通过**。两线全过 → **达标，可上架**。

## 五、诚实记录（不得隐去对结论不利的证据）

1. **裸模型在可读性与叙述连贯度上明显更好。** B 组的纪要是一份可以直接给人看的文档；A 组的产物是给机器读的紧凑结构，人读起来更硬。**本报告不为这一项计分，属观察项**——但它是真实差距，不得因为「不影响判分」就不写。
2. **增益的构成不平衡。** 400% 里有 60 分来自「越界拒绝 + 结构一致性」这两项**裸模型在结构上就无法提供**的能力。如果只看内容事实，两组的重叠度很高。因此本报告同时给出「只算反编造」的 186% 这一中性口径。
3. **同源自评偏差。** A 组由模型按 `SKILL.md` 执行、B 组由同一模型按「裸作答」形态模拟，**判分者也是同一个模型**。跨模型稳定性**未验证**。
4. **B 组是作者手写的模拟，不是真实并发采样。** 这弱化了 B 组分数的代表性；真实裸模型的输出可能在「结构一致性」上略好（例如用户要求固定模板时）。但「无脚本约束 → 不可字节复现、不可校验」这一点是结构性的，不会因采样而改变。
5. **本题的 rubric 由作者自定**，不存在外部标定的基准分。
