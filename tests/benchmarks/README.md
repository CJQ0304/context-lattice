# 基准与探针

这里的脚本产生**文档里那些实测数据**。它们不是验收集的一部分（不进 CI），但都在，所以数字可复核。

## 依赖

| 需要 | 用在 |
|---|---|
| 标准库 | 全部 |
| `tiktoken` | `realworld-probe.py` / `locality-probe.py` / `rw-cost.py` / `gate-probe.py` / `measure-capacity.py`（缺省时退化为字符数，但**不要**用退化值去引用文档里的 token 数） |

|---|---|---|

## 两条口径纪律

1. **分母 = 交付包边界，不是整仓。** 所有「语料全量 T」都走 `tests/pkg_boundary.py`。仓库里加一个开发目录就换一个 T，会让已发布的数字悄悄失效。
2. **交给 `plan` 之前先把语料摊平。** `plan` 是通用工具，只按 `.git/__pycache__` 之类通用规则排除，它不认识本仓库的 `tests/` `docs/`。不摊平就会出现「同一份报告两个分母」。

## 绝对值绑定版本

语料就是本交付包自身，改一次文档 T 就变。**引用数字时请连版本号一起引**；相对量（净省百分比、断点位置）才是稳定的那个。
